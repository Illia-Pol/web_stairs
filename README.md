# Сайты и стратегия для бизнеса бетонных лестниц

## Структура
- `BUSINESS_MODEL.md` — бизнес-модель и план масштабирования.
- `variant-1/` — первый MVP-вариант сайта.
- `variant-2-premium/` — второй премиальный вариант сайта.
- `variant-3-premium-dark/` — третий премиальный вариант в темной теме.
- `variant-4-infinity/` — ваш четвертый вариант (референс палитры).
- `variant-5/` — первый сайт с палитрой четвертого варианта.
- `variant-6/` — усиленный `variant-5` с блоками из референса (каталог типов, преимущества, FAQ, фон-слайдер).

## Что настроить перед запуском
1. Контакты в `script.js` внутри каждого варианта.
2. Реальные фото кейсов в `styles.css`.
3. Фактические данные по срокам, гарантиям и портфолио.
4. Аналитику и CRM для обработки лидов.
