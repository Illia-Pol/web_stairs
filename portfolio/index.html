Портфолио бетонных лестниц

На странице собраны реальные и шаблонные карточки проектов. Можно фильтровать объекты по городам и быстро сравнивать типы лестниц.

Фильтр проектов по городу

Выберите город и посмотрите релевантные объекты. Для некоторых регионов добавлены шаблонные карточки - их удобно заполнять новыми фото по мере завершения проектов.

Для выбранного города пока нет карточек. Добавьте проекты в /assets/data/projects.js.

Структура данных для пополнения

Все карточки хранятся в /assets/data/projects.js. Для нового проекта добавьте:

  • Город и citySlug для фильтрации.
  • Тип лестницы, краткое описание и теги.
  • От 1 до 3 фото (или пустой массив как шаблон).

FAQ

Частые вопросы

Почему часть карточек отмечены как шаблонные?

Это заготовки под новые кейсы по регионам. Они нужны, чтобы владельцу сайта было удобно быстро публиковать объекты в едином формате.

Можно ли фильтровать портфолио по ссылке из гео-страницы?

Да, гео-страницы ведут на портфолио с параметром города, чтобы пользователь сразу видел релевантные проекты.

Где менять порядок проектов?

Порядок задаётся в массиве /assets/data/projects.js. Достаточно переставить объекты местами в файле.
